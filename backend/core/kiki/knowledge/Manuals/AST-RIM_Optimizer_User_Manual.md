# AST-RIM Optimizer User Manual

## Overview of AST-RIM Optimizer
The AST-RIM Optimizer (Adaptive Supply Chain & Resource Management Optimizer) is an advanced predictive scheduling engine integrated into FINPIXE ERP. It dynamically calculates optimal reorder points, safety stock buffers, and warehouse fulfillment routes using multi-variable constraint algorithms.

### Key Capabilities:
1. **Dynamic Reorder Point Calculation**: Automatically adjusts inventory safety thresholds based on lead time volatility.
2. **Resource Allocation Engine**: Minimizes warehouse picking costs by optimizing storage bin placement.
3. **Multi-Warehouse Routing**: Routes order fulfillment to the nearest regional distribution node.
